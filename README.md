# 쿵덕 육성게임

우리 집 고양이 **쿵**과 **노덕**을 키우는 안드로이드 다마고치 + 진화 게임. 자세한 기획은 [SPEC.md](SPEC.md).

## 폰에 설치하기 (PC 없이)

1. 어느 브랜치든 푸시하면 GitHub Actions 가 디버그 APK 를 빌드해서 **Releases** 에 올립니다.
   - 저장소 페이지 → 오른쪽 **Releases** → 맨 위 `쿵덕 #번호` → `kungdeok-번호.apk` 를 눌러 내려받기
   - 빌드는 3~5분쯤 걸립니다. 진행 상황은 **Actions** 탭에서 볼 수 있습니다.
2. 내려받은 APK 를 열고 "출처를 알 수 없는 앱 설치"를 허용하면 설치됩니다.
3. 새 버전도 같은 방법으로 설치하면 덮어쓰기 됩니다. 모든 빌드가 저장소의 고정 디버그 키
   (`keystore/debug.keystore`)로 서명되어 있어서 **앱을 지우지 않아도 되고 저장 데이터도 유지**됩니다.

## 처음 켜면

- **방** 탭: 돌봄 버튼 (쓰다듬기, 밥, 간식, 놀아주기, 빗질, 재우기). 위쪽에서 대상(쿵/노덕/둘 다)을 고릅니다.
- **상태** 탭: 레벨, 경험치, 4가지 상태, 다음 진화 조건
- **도감** 탭: 만난 형태 목록, 못 만난 형태는 실루엣
- 하루 한 번 앱을 열면 선물 상자, 걸음 수는 상태 탭에서 확인 (처음에 '신체 활동' 권한 허용)
- 두 마리 모두 궁극체 + 사이좋음 100 이면 방 화면에 **합체** 버튼 (하루 한 번, 30분)
- **캣타워** 탭: 층별 턴제 전투 (냥냥펀치, 쿵/노덕 기술, 간식으로 회복). 5층마다 보스, 이기면 골드·경험치
- **상점** 탭: 밥·간식·장난감·빗(가방에 쌓여서 상태 탭에서 쿨다운 없이 사용), 방 가구, 고양이 꾸미기
- 실제 버릇: 새벽 5~6시 깨우기 알림, 밤에 우다다, 기분 좋으면 꾹꾹이, 박스를 사 두면 박스에 쏙
- **설정** 탭: "화면 위에 띄우기"를 켜려면 먼저 **다른 앱 위에 표시** 권한을 허용하세요.
  - 화면 위 고양이: 톡 = 머리 위에 작은 돌봄 메뉴(쓰담·밥·간식·놀기·빗질·재우기·앱 열기, 상태 막대),
    꾹 = 앱 열기, 드래그 = 옮기기
  - 알림창의 **숨기기/보이기** 버튼으로 잠깐 숨길 수 있습니다.

## 개발 메모

- 원본 그림: `raw/` → `python3 tools/process_sprites.py` → `sprites/large`, `sprites/small` (앱 assets 로 그대로 쓰임)
- 애니메이션 프레임: 직접 그린 프레임을 `raw/<이름>_walk1.png`, `_walk2.png`, `_sleep.png` 로 넣으면
  스크립트가 그것을 쓰고, 없으면 원본 그림에서 자동으로 만든다.
- 저장 데이터 구조(Room)를 바꾸면 `AppDatabase` 의 version 을 올리고 `AutoMigration` 을 추가한다.
  CI 가 `tools/check_migration.py` 로 이전 버전 데이터가 살아남는지 확인한다.
- 빌드: `./gradlew assembleDebug`
- 단위 테스트 + 화면 스냅샷: `./gradlew testDebugUnitTest`, `./gradlew recordPaparazziDebug`
